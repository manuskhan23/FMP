# 🗂️ FMP — Frontend Mini Projects

A collection of small frontend projects built with vanilla JavaScript, HTML & CSS during early web development learning.

## 📦 Projects Included

- **Quiz App** — Interactive quiz application with multiple-choice questions, score tracking, and instant feedback
- **Todo App** — Task management app with create, read, update & delete functionality, and user login

## 🛠️ Tech Stack

| Category | Technology |
|----------|------------|
| Structure | HTML5 |
| Styling | CSS3 |
| Logic | JavaScript (Vanilla) |

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Edge, Safari)

### Running Locally

1. Clone the repository:
```bash
git clone https://github.com/manuskhan23/FMP.git
cd FMP
```

2. Navigate to any project folder and open `index.html` in your browser, or use a local server:
```bash
npx serve .
```
